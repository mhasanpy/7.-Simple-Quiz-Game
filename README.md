An interactive, terminal-based quiz game built with Python. Test your knowledge across multiple topics, track your score, and get instant feedback on your answers. Perfect for beginners learning Python fundamentals through a real project!

## 🎮 Game Features

- 📝 Multiple-choice questions on various topics
- ✅ Instant feedback on correct/incorrect answers
- 📊 Final score display with percentage
- 🔄 Option to play again
- 🎨 Clean, user-friendly terminal interface
- 📈 Score tracking throughout the game

## 🎯 Topics Covered in This Project

This game demonstrates the following Python concepts:

| Concept | How It's Used |
|---------|---------------|
| **Lists** | Store questions, options, and answers |
| **Dictionaries** | Organize question data (Q&A pairs) |
| **Loops** | Iterate through questions and handle game flow |
| **Conditionals** | Check answers and provide feedback |
| **Functions** | Organize code into reusable blocks |
| **User Input** | Get and validate player responses |
| **String formatting** | Display clean, formatted output |
| **Error handling** | Handle invalid inputs gracefully |
| **Variables** | Track score, question count, and game state |
